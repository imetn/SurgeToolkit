## Overview
The `SurgeToolkit` repository is a collection of various Modules, Scripts, and other tools related to the Surge software.

## Security Boundary

This repository only contains rules, modules, scripts, and examples intended for public sharing. Subscription URLs, proxy credentials, certificates, private keys, and any Gist URLs or content must never be committed. See [CONTRIBUTING.md](../CONTRIBUTING.md) for details.
